# 3D Structural Studio — Release Notes

**From Bioinspired Images to Executable Structural Models**

3D Structural Studio brings interactive mechanics and archived structural research into one application.

- Three executable cases: Twin-Arch Web Bridge, Loop Towers and Woven-Wing Pavilion, with model/result downloads and Blender Export.
- H0–H3 comparisons with linked cameras, difference and transparency overlays, source identities and engineering schematics.
- The idealized B1+ final26 demonstration: a gravity-aware, member-screened **2.7658% modeled tube-mass reduction** in a 14-source-node/19-member model. Only members 1520/1538 change wall thickness from 26.404 to 21.404 mm at unchanged 640 mm outer diameter.
- 34 archived response records, identified by model, load, engine, mesh and verification scope.
- A concise Research Data & Source Code section, with provenance and checksums retained in downloadable manifests.

The research-data release is not yet published. Contextual model, result and schematic downloads remain available. Repository addresses, existing routes and scientific identifiers are unchanged.

The R6 human–AI proposal and deterministic studies retain their distinct outcomes, including rejection, NO-GO, trade-offs, STOPPED and INCONCLUSIVE findings. See [Scientific Scope](../../public/research/SCIENTIFIC_SCOPE.md).

See [Verification Coverage](VERIFICATION.md) for automated test results, browser coverage and remaining verification requirements.
