# Standalone Distribution

3D Structural Studio is a static Vite/React application. It runs in a browser without an account, application server or database. Relative asset URLs support hosting at either a domain root or a repository subpath.

See [Getting Started](README.md#getting-started) for installation, [Data and Reproducibility](docs/research/REPRODUCIBILITY.md) for source/data packaging, and the [Maintainer Deployment Guide](docs/maintainers/DEPLOYMENT.md) for static hosting and GitHub Pages.
